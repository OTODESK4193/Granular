## 1. まずは音を出す

**OTODESK / 24ボイス スケール量子化グラニュラーシンセ（VST3 / Standalone）**  
**Version:** v1.1.0 (Build 016)

読み込んだオーディオファイルを「粒（グレイン）」に分解して再構築するグラニュラーシンセです。環境音やノイズ素材でも音楽的な音程を持った楽器として演奏でき、強力な変調マトリクス・アルペジエイター・5スロットFXチェーン・150種類のファクトリープリセットを備えています。

### インストール

1. `Granular.vst3` を以下のフォルダにコピーします。
   ```
   C:\Program Files\Common Files\VST3\
   ```
2. DAW でプラグインを再スキャンします。

### 最初の一歩

1. オーディオファイル（WAV / AIFF / MP3 / FLAC / OGG）を**波形エリアにドラッグ＆ドロップ**、またはヘッダーの **LOAD** ボタンから読み込みます。
2. 読み込むと自動でピッチ解析・音量正規化が行われ、**元の音程を保ったまま鍵盤で演奏**できます（C3＝原音の高さ）。
3. MIDIキーボードを弾くと発音します。

> **ヘッダーボタン**
> - **PLAY DRY**：取り込んだ原音をそのまま試聴します（もう一度押すと停止）。
> - **PANIC**：万が一音が鳴り止まなくなった際に押すと、全ボイスおよび残響を即座に強制消音・リセットします。
> - **RANDOM**：8種類の音楽的アーキタイプ（Lush Pad / Modal Crystal / Diatonic Swarm / Formant Lead / Euclid Arp / Gate Groove / Granular Bass / Kinetic Lab）からインテリジェントに音色を生成し、安全なMODルーティング（3〜6系統）と重複なしFX詳細設定を自動構成します（出力ゲイン・同時発音数・カラーテーマは保護）。
> - **BROWSE**：下部に3カラム式のプリセットブラウザを展開／収納します。

## 2. 画面の構成と操作

上部に常時**ドット波形ディスプレイ**が表示されます（読み込んだ音の周波数を解析し、低域＝暖色／高域＝寒色でスペクトル着色。発音中は生成された粒がリアルタイムに舞います）。  
その下に **6つのタブ**があり、下部の操作パネルが切り替わります。

| タブ | 内容 |
|------|------|
| **MAIN** | グレイン生成・ピッチ・エンベロープ（ADSR）・SAMPLE（再生位置/範囲）・MOTION・マスター・先読みリミッター |
| **ENGINE** | 合成エンジン切替（Granular/WSOLA/TD-PSOLA）・Concatenative Atlas・ダイアトニックスウォーム・グレインSVF・モーダル共振バンク |
| **ARP** | アルペジエイター＋ユークリッドリズム（E(k,n,r)）＋82種スケールクオンタイズ |
| **MOD** | ポリフォニック変調（LFO ×4 / Per-Voice Env ×3 → 16スロットマトリクス / 77宛先） |
| **FX** | 5スロットのエフェクトチェーン（重複禁止・D&D並べ替え対応） |
| **CONFIG** | 素材解析モード・リミッター設定・同時発音数・フィルタ特性・カラーテーマ・GUIスケーリング |

### 便利な操作系
- **GUIの拡大・縮小**：ウィンドウ右下のドラッグハンドルで **75% 〜 200%** の範囲でウィンドウサイズをアスペクト比固定で自由に変更できます。変更したサイズはDAWのプロジェクトに保存されます。
- **数値の直接入力**：各ノブを**右クリック**すると、数値をキーボードから直接タイプ入力できます。
- **モジュレーションのクリア**：MODマトリクスの Amount スライダーは**ダブルクリック**で素早く `0.0` にリセットできます。
- **安全確認**：INIT やプリセット削除などの破壊的変更には確認ダイアログが表示されます。

## 3. MAIN タブ

- **GRAIN**：
  - **SIZE**：グレインの長さ（0.02s 〜 0.5s）
  - **DENSITY**：粒の密度（オーバーラップ 0.25倍〜64倍、1/√overlap で自動音量補正）
  - **SPRAY**：グレイン発生位置のランダムな散らばり（0.0 〜 1.0）
  - **JITTER**：グレインごとのピッチのランダムな揺らぎ（0 〜 2400 cents、**量子化前**に加算されるためスケールから外れません）
  - **PAN**：ステレオの広がり（Pan Spread）
  - **SPEED**：再生速度（0.0 〜 2.0）
  - **WINDOW**：グレインの窓関数（Hanning / Triangle / Square / Asymmetric）
  - **REV**：グレインの逆再生トグル
- **PITCH**：OCTAVE（-3〜+3）/ SEMI（-24〜+24st）/ FINE（-100〜+100ct）
- **TONE**：Karplus-Strong型コムレゾネーター（0.0〜1.0）。鍵盤の音程に同期して弦を弾いたような共鳴・音程感を付加します。内部でソフトクリップされており過大入力でも安全です。
- **P-SYNC**：音程同期グラニュラー。グレインの発火周期を演奏ノートの周波数に厳密にロックし、ノイズ素材でも明瞭な音程感を与えます。
- **ENVELOPE**：べき乗アタック（0.5ms〜10s）と指数ディケイ／リリースを備えた高精度ADSR。
- **SAMPLE**：POSITION（再生位置）/ START / END（使用範囲）。波形上のマーカーをドラッグしても直感的に調整可能です（端には約3msのクロスフェードがありクリックを防止）。
- **MOTION**：再生位置の移動モード（Forward / Backward / Ping-Pong / Random）。
  - **S-SYNC**：START〜END領域をホストテンポ（1拍〜8小節）に完全同期してスキャンします。
  - **Randomモード**：プレイヘッドが移動するのではなく、一定間隔でランダムな位置へジャンプします（SPEEDノブでジャンプ頻度を制御、0で完全フリーズ）。
- **MASTER**：HPF / LPF（TPTステートバリアブルフィルタ、1サンプル平滑化）/ GAIN / DRY-WET（FXラック全体のブレンド比、MOD変調可能）
- **LIMITER**：CEILING（マスター直前の即時アタック・ブリックウォールリミッター天井値）

## 4. ENGINE タブ（Phase 4 拡張エンジン＆モーダル共鳴）

市販グラニュラーを超える音響合成・音響物理エンジン群です。すべてのノブが MOD マトリクスのターゲットに対応しています。

- **ENGINE & SWARM**：
  - **ENGINE MODE**：`Granular` / `WSOLA`（相互相関による位相整列オーバーラップ）/ `TD-PSOLA`（ピッチとフォルマントの完全分離）を選択。
  - **FORMANT**：TD-PSOLA 時に音程を変えず声質やボディの太さ（-12〜+12半音）を独立シフト。
  - **SWARM MIX**：再生中のスケール音階に沿った和音グレイン群を自動分散配置。ボイス間の衝突回避スケジューラも同時稼働。
  - **ATLAS PITCH**：素材の各局所区間のピッチ（F0）を個別検出し、フレーズ素材でも鍵盤通りの正確なポリフォニック楽器として鳴らします。
- **CONCATENATIVE ATLAS**：
  - **TIMBRE / ATLAS AMT**：インジェスト時に構築した全グレイン音色地図を O(log N) で探索し、指定した明るさ（ダーク〜ブライト）を持つグレイン位置へ発生点を引き寄せます（ゼロクロス自動スナップ・過渡追従窓付き）。
- **GRAIN SHAPE & PER-GRAIN SVF FILTER**：
  - **SKEW**：グレイン包絡を打楽器的な急立ち上がり（負）〜逆再生風のスウェル（正）へ歪ませます。
  - **CHIRP**：グレイン1粒ごとに連続的なピッチグライド（-12〜+12半音）を付与。
  - **FILTER MODE / CUTOFF / RESONANCE / FLT JITTER**：グレイン1粒単位で独立した Zavalishin TPT SVF（Off / LP / BP / HP / Notch）を適用し、ジッターで粒毎にカットオフを散らします。
- **SCALE-TUNED MODAL RESONATOR BANK**：
  - **RATIO MODE**：8基のステレオ物理共振器を `Scale`（ScaleQuantizer の音階に厳密調律）、`Harmonic`、`Marimba`、`Bell`、`Plate` へ切換。
  - **MODAL MIX / DECAY / DAMPING / INHARM**：T60減衰・高域空気減衰・剛性非調和分散をサンプルレート非依存で演算し、グラニュラー出力を物理ボディで共鳴させます。

## 5. ARP タブ（アルペジエイター＆ユークリッドリズム）

### アルペジエイター
鍵盤で押さえた和音を自動でリズミカルに分解・走査して演奏します。
- **Pattern**：25種類のパターン（Up, Down, Up-Down, Down-Up, Up-Down (Incl), Converge, Diverge, Pedal Low, Pedal High, As Played, Random, Random Walk, Chord, Inward, Outward, Thumb Bass, Pinky Top, Zig-Zag 他）
- **Rate**：テンポ同期（1/1 〜 1/32、付点・三連符対応）またはフリー（0.5 〜 30 Hz）
- **Octaves**：オクターブ範囲（1 〜 4 オクターブ）
- **Duration / Gate**：ノート長（Gate % または 1/32〜1/4 固定音価）
- **Latch**：鍵盤から手を離しても演奏を継続するホールド機能
- **Euclidean Rhythm (EUCLID / STEPS / FILLS / ROT)**：ビョルクルンドのアルゴリズムによりステップ発音／休符をユークリッド分布させ、変拍子やポリリズムのアルペジオを生成。

### スケールクオンタイズ（SCALE QUANTIZE）
本機最大の特徴である**ポストモジュレーション・スケールクオンタイズ**を集中コントロールします。
- **SCALE QUANTIZE（On/Off トグル）**：スケールクオンタイズ機能の有効／無効を切り替えます。
- **Key**：基準キー（Auto＝サンプル解析結果を使用、または C 〜 B の固定指定）
- **Scale**：**全82種類**の階層カテゴリ選択式スケール（Chromatic / Major / Minor / 教会旋法 / 日本・民族音階 / ジャズ / インドラーガ / 和音アルペジオ等）
- **ScaleNote 表示**：選択中の Key と Scale に基づき、スケールの構成音（例: `C, D, E, F, G, A, B`）がリアルタイムに表示されます。

## 6. MOD タブ（ポリフォニック変調）

左側のサブタブで**ソース**を設定し、右側の **16スロット・マトリクス**（Page 1 / Page 2）で自在にルーティングします。

### ソース群（全13種）
- **LFO ×4**：波形6種（Sine / Triangle / Saw / Square / S&H / RK4 Lorenz Chaos）。テンポ同期（1/1〜1/32）またはフリー（0.02〜20 Hz）
- **Env ×3（ポリフォニック対応）**：ADSRエンベロープを全24ボイス各自が独立して保持・進行します。**LOOP** オンで Attack-Decay 循環LFOとして動作。
- **MIDIソース**：Velocity / Note / Mod Wheel / Random（ノート毎S&H）/ Aftertouch（Poly Aftertouch・CC74 MPE Slide 対応）

### 16スロット・マトリクス（全77宛先）
- 各行で **Source × Amount → Destination** を設定（カテゴリ階層メニューから全77宛先を選択）。
- **UNI/BI トグル**：Unipolar（0〜+1）または Bipolar（-1〜+1）の極性を切り替え。
- **真のポリフォニック変調**：ボイスパラメータへのアサインはノート毎に独立計算（例：強く弾いた高い音だけ Per-Grain Filter が開き、弱い低音は閉じたまま維持）されます。
- **ピッチ変調の魔法**：ピッチ関連の変調先（Octave, Semi, Fine, Pitch Jitter等）はすべて**スケールクオンタイザーの手前で加算**されるため、どれほど過激に変調してもスケールから外れません。

## 7. FX タブ（エフェクトラック）

高品位な5スロットのエフェクトチェーン。ヘッダーのドラッグ＆ドロップで接続順序を自由に入れ替えられます。

### 搭載エフェクト（全6種）
1. **Saturation (ADAA)**：反微分アンチエイリアシング処理による真空管・テープ・トランジスタ等の**10種類の歪みアルゴリズム**。Pre-HPFとTrim付き。
2. **Ensemble Chorus**：厚みのあるステレオ空間を広げるコーラス（Rate, Depth, Width）。
3. **Tape Delay**：ダッキング機能（Duck）とダンピングを備えたテンポ同期ディレイ。
4. **Freeze**：最大1000msの粒状フリーズ・アンビエントリバーブ。
5. **Shimmer Reverb**：オクターブシフターを内蔵した16ch FDNシマーリバーブ。
6. **FormantGate**：母音フォルマント変化を伴うリズミックなスタッター・ゲート（Rate, Pattern, Depth, Decay, Vowel）。

> **重複防止の排他制御**  
> いずれかのスロットで使用中のエフェクトは、他のスロットでは選択できず自動的にグレーアウト（非活性化）されます。ヘッダーの **RANDOM** ボタン押下時も重複なしシャッフルにより常に異なるエフェクトが選定されます。

## 8. CONFIG タブ

- **MATERIAL**：素材解析モード（Auto / Percussive / Melodic / Vocal）。切り替え後、ヘッダーの **ANALYZE** ボタンで再解析します。
- **LIMITER RELEASE**：先読み式ブリックウォールリミッター（約1.5ms・PDC自動通知）の復帰時間（1〜500ms）
- **POLY**：最大同時発音数（1〜24ボイス）
- **FILTER SLOPE**：マスターHPF/LPFの遮断スロープ特性（12 dB/oct または 24 dB/oct）
- **COLOR THEME**：10種類の洗練されたカラーテーマ（Midnight, Sakura, Ocean, Forest, Sunset, Mono, Neon, Vaporwave, Amber, Arctic）。

## 9. プリセットブラウザ

ヘッダーの **BROWSE** ボタンを押すと、下部にプロ仕様の **3カラム式階層プリセットブラウザ** が展開されます。

### 3カラム構成
1. **左カラム「CATEGORY」**：
   - `All`（全件表示）
   - `Favorites ★`（お気に入り登録されたプリセットのみ）
   - 12のファクトリカテゴリ（`Pads & Ambient`, `Textures`, `Rhythmic`, `Bass`, `Leads`, `Cinematic`, `Glitch`, `Experimental`, `Pitch`, `Engine & Formant`, `Swarm & Modal`, `Euclid & GrainFX`）
   - `User`（ユーザーが作成・保存したプリセット）
2. **中央カラム「SUBCATEGORY」**：
   - 左で選択したカテゴリに属するサブカテゴリ一覧を動的に表示（先頭は「All」）。クリックで即座に目的のサブカテゴリに絞り込めます。
3. **右カラム「PRESET」**：
   - 絞り込まれたプリセットの一覧。クリックで瞬時にロードされます。▲▼ボタンやキーボードの ↑↓ キーでも順送り試聴が可能です。

### お気に入り（★）機能
- リスト行の左端にある **★ / ☆ アイコン（ゴールド色）** をクリックするだけで、ワンクリックで即座にお気に入り登録／解除できます。
- 行の**右クリックメニュー**からも「Mark Favorite ★ / Remove from Favorites」が選択できます。

### ユーザープリセットの保存
1. ブラウザ右上の **SAVE** ボタンを押すと保存ダイアログ（AlertWindow）が表示されます。
2. **Category**（既存ファクトリカテゴリまたは User から選択・自由入力可）、**Subcategory**（自由入力）、**Preset Name**（プリセット名）を入力して「Save」を押します。
3. ユーザープリセットは `ドキュメント / OTODESK / Granular / Presets /` に `.xml` 形式で保存され、次回起動時やブラウザ更新時にそのカテゴリ・サブカテゴリへ正しく分類されます。
4. 不要になったユーザープリセットは右クリックメニューから安全に削除（確認ダイアログ付き）できます。

> **サンプルの保存について**：プリセットには巨大な音声ファイルそのものは埋め込まず、**サンプルのファイルパス**をスマートに記録します。元のファイルがPC上に残っていれば、プリセット読み込み時に自動でバックグラウンド再ロードされます。

### 全150種のファクトリープリセット
B016/B017において全プリセットのスケール・MOD極性・サチュレーションゲイン補償を検証・再調整し、さらに Phase 4 新機能に特化した30種（3カテゴリ）を追加しました。
- **既存80種**：Pads & Ambient (10), Textures (10), Rhythmic (10), Bass (10), Leads (10), Cinematic (10), Glitch (10), Experimental (10)
- **「Pitch」カテゴリ（40種）**：
  Toneコムレゾネーター共鳴と時間軸・ARP・Gateを駆使した8つの明確なサブカテゴリ（各5種）で構成：
  - **Pluck (5)**：急峻なアタックとディケイによる撥弦・打弦楽器の感触。
  - **Bell (5)**：金属的な硬度、Fineモジュレーション、Shimmerリバーブ。
  - **Lead (5)**：滑らかなビブラート、表現力豊かなソロ演奏用。
  - **Pad (5)**：豊潤な厚み、超低速LFOによる壮大なスウィープ。
  - **Bass (5)**：低域の芯、バイト感のあるアタック。
  - **Arp (5)**：内蔵アルペジエイター連動シーケンス。
  - **Gate (5)**：FormantGate による鋭いスタッター・スライス。
  - **Drone (5)**：終わらない持続音、Ping-Pong、ダークな残響と唸り。
- **Phase 4 新規ショーケース（30種）**：
  - **Engine & Formant (10)**：WSOLA 位相整合ストレッチ、TD-PSOLA 独立フォルマントシフト、Grain Atlas 音色ナビゲーション。
  - **Swarm & Modal (10)**：ダイアトニックスウォーム和声レイヤーと8モードモーダル共振器。
  - **Euclid & GrainFX (10)**：Bjorklund ユークリッドアルペジオ、グレイン内 Skew / Chirp、グレイン毎 Zavalishin SVF。

## 10. 使いこなしのヒント

- **ノイズを音楽的なパッドに仕立てる**：環境音や風の音をロードし、TONE を 0.5 付近、Size を 0.2s、Density を 0.7 に設定し、SCALE QUANTIZE をオンにして好きなスケールを選択します。これだけで美しいアンビエントパッドになります。
- **過激に変調しても音が外れないリード**：MOD タブで LFO 1 を `Semi` または `Fine` に最大量でアサインします。ピッチが激しく上下に揺れ動いても、ポストクオンタイズのおかげで完全にスケール内の音階だけで跳ね回ります。
- **テンポ同期の呼吸するテクスチャ**：MOTION を Ping-Pong にし、S-SYNC をオンにして Scan を 2 Bars に設定。LFO(SYNC) で Filter や Density を揺らせば、楽曲のビートと有機的にシンクロするグラニュラーが得られます。
- **音が止まらなくなったときは**：ヘッダーの **PANIC** ボタンを押せば、全ボイスとディレイ・リバーブの残響が一瞬で安全にリセットされます。

### トラブルシューティング
- **CPU負荷が高い・音が途切れる**：CONFIG タブで **POLY** を下げる（例: 24 → 12）、または MAIN タブで **DENSITY** を少し下げてください。
- **カラーテーマが一部切り替わらない**：ノブのアクセント色はグラフィック最適化のため起動時にキャッシュされます。プラグイン画面を一度閉じて開き直すと完全に反映されます。
